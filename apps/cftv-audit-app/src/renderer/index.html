Limites de verificação

Heartbeat (conectividade automática)

O sistema escolhe automaticamente qual intervalo usar por gravador, dependendo da camada de checagem que está funcionando nele (veja a aba Gravadores). Câmeras individuais sempre usam o intervalo rápido.

Agendamento

Formato cron: minuto hora dia-do-mês mês dia-da-semana. Ex: 0 7 * * 1 = toda segunda-feira às 07:00.

Telegram

Crie um bot com o @BotFather no Telegram para obter o token, e use o @userinfobot (ou adicione o bot a um grupo) para descobrir o Chat ID.

WhatsApp Em breve

Integração planejada — requer aprovação da Meta Cloud API ou um provedor como Twilio.

E-mail Em breve

Integração planejada via SMTP.

Servidor central (monitoramento multi-cliente)

Envia um resumo de conectividade (e da última auditoria completa) para o servidor central — usado para consolidar o monitoramento de vários clientes num só lugar. A API key é gerada no servidor central com npm run criar-cliente.
